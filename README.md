# FOOTBALL HUB
Football academy & club management system (HTML5, CSS3, vanilla JS, LocalStorage, Chart.js, Lucide).

## Run
Open `index.html` in a browser. An internet connection is needed for the Chart.js, Lucide and Google Fonts CDNs. No install or server required.

## Features
Dashboard (live stats), players (CRUD, search, filter, sort, profiles), teams (CRUD, squad assignment, comparison table), matches (schedule, results, history), analytics (leaderboards, charts, rankings), training & attendance (sessions, present/late/absent, percentages, filters), fees tracking (PKR, paid/unpaid, per-team chart), staff directory, SVG crests, kit avatars and pitch formations, player photo upload, settings (theme, profile, demo reset).

## Notes
Data lives in LocalStorage under `footballhub_v1`; clear it or use Settings → Reset to restore demo data. Team standings are calculated from finished matches (win 3, draw 1). Player goals/assists/appearances are edited on the player record.

The Clubs page shows famous clubs as kit-colour artwork; official club crests are trademarked, so none are included.
